# ChessC

## (fourth chess rebuild this time in C)

-Bitboard style board representation, 12 64 bit integer numbers used to represent piece positions
[Bitboards](https://chessprogramming.org/Bitboards)
-Utilizing pesto evaluation tables
[Pesto evaluation](https://chessprogramming.org/PeSTO%27s_Evaluation_Function)
-Some rudimentary compatibility with UCI (universal chess interface)
-Not properly tested yet to determine rating, i would guess around 1500~ from limited manual testing
-GUI built with raylib, textures hand drawn on ipad!
